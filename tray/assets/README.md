# assets/

Tray icons embedded by package `assets` (`//go:embed`) and used by `internal/tray`. **Generated**
from the brand masters by `node brand/generate-icons.mjs` (see `brand/README.md`); do not edit by
hand.

| File | Used on | Notes |
|---|---|---|
| `icon.png` | Linux (StatusNotifier), macOS regular icon | 64×64, white mark on transparent, cropped (panels are dark) |
| `icon.ico` | Windows | PNG-compressed ICO, 16/32/48/256, dark variant |
| `icon-template@2x.png` | macOS menu bar (template image) | mark only, black + alpha, 44×44 |
