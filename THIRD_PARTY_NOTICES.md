# Third-party notices

Tunnelio is built on other people's software, fonts and data. Their licences apply to them, and all
of them allow them to be distributed together with Tunnelio's own code under the AGPL-3.0
([`LEGAL.md`](LEGAL.md)).

This page describes what each distributed part contains and points to the full texts. The licence
texts themselves travel with each part, generated at build time from the exact versions inside it:

| Part | Where the full licence texts are |
|---|---|
| **Web app** | `third-party-licenses.txt`, served next to the app (in Settings → General → About, "Third-party licenses"). Generated by `web/vite.config.ts`, with `web/licenses/`. |
| **Computer app** | `THIRD_PARTY_LICENSES.txt` in every package: next to `tunnelio.exe` in the `.zip` and the MSIX, in `/usr/share/doc/tunnelio/` from the `.deb`, and in `Tunnelio.app/Contents/Resources/`. Generated by `tray/scripts/third-party-licenses.sh`. |
| **Server image** | `/app/THIRD_PARTY_LICENSES-python.txt` (the Python packages, written by `server/scripts/third_party_licenses.py` with `server/licenses/`), the web app's file in `/app/web-dist/`, and `/usr/share/doc/*/copyright` for the operating-system packages. |

Versions change with every release, so the generated files are the authoritative list. The tables
below describe the release prepared on 2026-10-18.

## Content from ollama.com

The server reads the public model list at [ollama.com/library](https://ollama.com/library) when it
runs, and shows it to signed-in users. The repository and the images keep only facts from it, in
`server/catalog/data/`: model names, capability labels, sizes, counts and dates. They do not keep
its descriptions. The test fixtures in `server/catalog/testdata/` follow the structure of those
pages, with facts like these and placeholder text of our own. Model names belong to their makers.
