# Test vectors

`vectors.json` is generated by `gen_vectors.py` (Python 3.12, `cryptography`, `argon2-cffi`):

```bash
python3 gen_vectors.py        # rewrites vectors.json; aborts if the RFC 9382 check fails
```

The generator contains a small *educational* P-256 + SPAKE2 implementation. It first
re-derives the first vector of RFC 9382 Appendix B (and asserts equality), then produces
the Tunnelio-specific vectors. See `docs/SPEC.md` §13 for what each key covers and which
implementation must pass it.

Rules:
- Both implementations (`tray/`, `web/`) load this file in their test suites and compare bytes.
- Never edit `vectors.json` by hand. Change the generator, re-run, commit both.
- A change that alters any vector is a protocol change and requires a `v` bump (SPEC §12).
